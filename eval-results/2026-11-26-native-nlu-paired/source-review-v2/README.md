# Native source-first review v2

These artifacts cover all three strategies on the same 1,861 frozen messages. The eligibility gate replays saved proposals at library revision `957985c` through the corrected checker. It excludes invalid, ungrounded, and materially incomplete circuits before model review. The final packets contain 3,907 distinct strategy groups, including 795 with one or more eligible interpretations. The 70 static L0 and 3,042 static L2 groups did not receive model grades.

Blind literal reviews by Luna and Sol assessed the same 795 eligible groups. Sol was the baseline for reported grades where both agreed at the acceptance threshold. A fresh Sol review adjudicated 270 threshold disagreements plus targeted calibration groups and source flags, 280 groups in total. The merger shares an exact accepted witness with other strategy groups that emitted it for the same message unless an independent reviewer explicitly rejected that exact witness. Its output records each chosen circuit and executable source-grounding checks. L9 and L10 are reserved because the frozen cohort has no compatible native reference set.

The witness-vote archive is separate from benchmark grading. An exact witness needs more than one direct affirmative judgment for annotation consideration. A blind singleton review examined selected witnesses without two unopposed affirmative votes. It confirmed 104 additional circuits for a total of 364 independently supported witnesses out of 393 distinct benchmark-accepted witnesses. No dataset annotation is written by this workflow.

`manifest.json` identifies the sample, predictions, schema and checker by digest. `review-execution.json` preserves stage wall times and token counts reported by the CLI. `pre-checker-replay/` preserves the strict no-residue gate and its two completed judgments. The final replay reused 730 model judgments per reviewer only where the source and the entire eligible candidate set were unchanged. The earlier `superseded-pilot/` used a different rubric and is excluded from all final counts. See the [review workflow](../../../tests/benchmark/meaning-review/native-workflow.md).
