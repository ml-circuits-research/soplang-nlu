# Terra rework of independently unresolved Sol sources

The first 100 eligible rework sources come from already-published Sol batches 000002 (48), 000003 (39) and 000004 (13), in original queue order. Fifty-nine previously failed static curation. Forty-one reached independent review and had no accepted candidate. Sources with an existing annotation were excluded.

The prompt supplies exact English, original and rejected circuits as drafts, and the static queue issue or independent rejection reasons by draft index. GPT-6.1 Terra may confirm an existing draft, revise it or generate one or two new interpretations. The same literal-source validator and single corrective attempt govern the output. Each eligible circuit receives compatible settled exact judgments or independent review by GPT-6.2 Sol and GPT-6.1 Sol, with GPT-6.2 Astra deciding their threshold disagreements.

The generation code is pinned at commit `4ed98c8` on branch `terra-sol-rework`. The export check at `3ed0526` requires two affirmative votes and no contrary adjudication. Exact matches, selection origin and input and model digests are recorded with the archive. Sol remains the main curation author. This experiment addresses its unresolved sources.

Terra recovered 75 of 100 sources, each with one strictly verified circuit. One was an unchanged draft; 74 were new or revised. All 75 circuits passed blind review, with Astra accepting the two circuits with threshold disagreements. No exact review identities matched a prior decision. The other 25 remained unresolved at the static gate. Generation took 207.2 seconds, excluding review. These were already unresolved sources, so this recovery percentage does not measure accuracy on the production distribution.
