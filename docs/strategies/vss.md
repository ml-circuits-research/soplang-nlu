# vss (renamed hmm-rules)

This page: a pointer kept at the old path, for links in old run folders under `eval-results/`. Kind: Reference.

The strategy `vss` was renamed `hmm-rules` on 2026-11-27: it is a hidden Markov model plus rules, not a vector-symbolic reader ([hmm-rules: Name](../formalizers/hmm-rules.md#name)). Its pages:

- [hmm-rules](../formalizers/hmm-rules.md): what the formalizer is, how it reads, speed and cost, limits, how to run it.
- [hmm-rules in depth](../hmm-rules/README.md): the reader in detail, from training to the written circuit.
- [The nlu-schema period](../project/nlu-period.md): what the strategy did before the syntax schema, which is what the old run folders that link here measured.

The real vector-symbolic reader is `rvss`, being built in `strategies/rvss/` ([Formalizers](../formalizers/README.md)).
