# Prolog

Node loads SOP declarations and aligns evidence spans. SWI-Prolog matches and ranks interpretations using language frames, role rules and argument sequences. The symbolic adapter always selects the world declarations and starts with empty example and template tables. World overlays can supply vocabulary and typed bindings. Native SOP checks validate the emitted circuits.

During integration, preserve the evidence for each alternative independently. Every participant, value and action needs support in the current utterance. Record the world configuration for reproducible evaluation.
