# Z3

The active reader uses MaxSMT to select compatible parts of speech, clause predicates, entity spans and grammatical roles. It models local attachments as alternatives with explicit constraints on the words and phrases each choice can use. For “Put the box on the table by the door”, Z3 can return both a clause-level attachment and an attachment to “table” for the second prepositional phrase. The circuit quotes the actual role words. Z3 also returns its objective, selected token classes and source ranges as engine diagnostics outside the SOP serialization.

The analysis uses English lexical facts and action frames from the configured worlds. Pronouns stay literal, and noun fragments use a topic link. The implementation handles local clauses and coordination. Nested clauses, long-distance dependencies, and unusual constructions can leave text unresolved or yield incomplete hypotheses.

Install the solver with `npm ci --prefix strategies/z3`. Supply a `knowledgeDir` containing SOP schemas, worlds and the native SOP runtime. Optional `worldPaths` can add supported lexical and catalog declarations. See the [strategy installation notes](../../strategies/z3/README.md).

The legacy benchmark path independently formalises against the `w.request` catalog. The saved November 25 replay included a bench request in which the material was treated as a link destination. Use comparable paired failures to test attachment, target binding and role evidence independently of schema validity.
