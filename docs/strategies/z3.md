# Z3

The reader constructs an SMT-LIB2 MaxSMT problem from the current text and a catalog of request keys. Hard constraints restrict compatible bindings. Solver objectives rank feasible candidates. A circuit can contain requests from several families. The reader exposes native verification results and unresolved spans, including directives the request schema cannot express.

Install the local solver with `npm ci --prefix strategies/z3`. Supply a knowledgeDir containing SOP schemas, worlds and the native SOP runtime. Additional worldPaths extend the vocabulary and request key declarations supported by the recognizers. See the [strategy installation notes](../../strategies/z3/README.md) for configuration and limits. Optional ambiguity diagnostics report solver objective margins and differences between proposals.
