# Reference

This page: the index of every reference page of this documentation, grouped by subject, including the reference pages that live in other sections. Kind: Explanation.

Reference pages hold exact facts to look up: names, options, file formats, rules. They do not teach. For the ideas, start at [Concepts](../concepts/README.md); for a task, see the [How-to guides](../guides/README.md). Current numbers are never repeated here: they live only on the [status page](../STATUS.md).
